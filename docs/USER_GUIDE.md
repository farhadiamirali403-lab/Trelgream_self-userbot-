# User Guide

## شروع

1. به Central Bot پیام `/start` بدهید.
2. از پنل، «🤖 مدیریت سلف» را بزنید و «🔗 اتصال حساب تلگرام».
3. شماره تلفن حساب تلگرام خود را وارد کنید.
4. کد تأیید (SMS / Telegram / Email / ...) را وارد کنید.
5. در صورت نیاز رمز 2FA را وارد کنید.
6. پس از موفقیت، Userbot شما به‌صورت خودکار شروع می‌شود.

## اشتراک

1. «💳 اشتراک» → «💳 خرید اشتراک» → انتخاب پلن.
2. شماره کارت نمایش داده می‌شود؛ مبلغ را واریز کنید.
3. تصویر/فایل رسید را ارسال کنید.
4. پس از تأیید ادمین، اشتراک فعال می‌شود.

## پنل

- 🤖 مدیریت سلف — وضعیت Userbot
- 🧩 قابلیت‌ها — فعال/غیرفعال‌سازی ماژول‌ها
- 💳 اشتراک — وضعیت و خرید
- 🆘 پشتیبانی — ارتباط با پشتیبانی
